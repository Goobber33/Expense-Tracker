# Expense Tracker (Java)

A console-based expense tracker built to demonstrate CSE 100 fundamentals:
- Classes/objects
- Loops/conditionals
- File I/O
- Basic collections

## Run
```bash
javac Expense.java ExpenseTracker.java
java ExpenseTracker
```

## Roadmap
